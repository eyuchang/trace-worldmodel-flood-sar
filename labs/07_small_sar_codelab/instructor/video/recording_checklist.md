# Recording and Publication Checklist

## Content lock

- [ ] Approved lab commit recorded.
- [ ] Standalone student workspace rebuilt and hash recorded.
- [ ] Clean extracted ZIP has completed `setup_workshop.py`, activation, and
      `python workshop.py check` without a package or model download.
- [ ] Every command in the script rerun from a clean extracted workspace.
- [ ] Private same-file reveal copy prepared; no solution filename or reveal
      command will appear in the capture.
- [ ] Expected outputs match the README and captions.
- [ ] SAR, evidence, TRACE, CLEAR, HOLD, allocation, refusal, and repair are
      defined before students must use them.
- [ ] Each recorded screen answers one student question and advances the same
      welfare-check story.
- [ ] The terminal walkthrough and student controller run both print the four decisions.
- [ ] No protected study command appears in shell history or suggestions.
- [ ] Final checklist matches the learning objectives in the student README.

## Privacy and security

- [ ] Generic username, hostname, prompt, and working directory.
- [ ] Desktop icons, menu-bar personal data, notifications, and recent files hidden.
- [ ] No email, Git token, SSH key path, remote URL, private issue, or browser session.
- [ ] No camera is captured.
- [ ] Human narration is recorded only when Jay separately approves it.
- [ ] Screen-only review draft inspected frame by frame at transitions.
- [ ] Video metadata contains no personal path, location, account, or device name.

## Visual and audio quality

- [ ] 1920×1080, 16:9, 30 fps.
- [ ] Terminal and editor text readable at 720p playback.
- [ ] Color is not the only indicator.
- [ ] The terminal walkthrough has spoken and captioned explanation.
- [ ] Human narration peaks below clipping and has no room noise.
- [ ] Silence and cuts do not remove command context.
- [ ] Final student checklist remains visible through the end.

## Captions and accessibility

- [ ] Captions edited into natural two-line phrases.
- [ ] Identifiers, numbers, and commands checked character by character.
- [ ] Speaker-independent information also appears on screen.
- [ ] Captions do not obscure terminal output.
- [ ] Transcript and student README linked in the final description.
- [ ] Playback reviewed at normal speed and with audio muted.

## Upload gate

- [ ] Repository/workshop links are public and approved before insertion.
- [ ] Title, description, chapters, thumbnail, and visibility reviewed.
- [ ] Copyright and provenance check complete for every visual asset.
- [ ] No emergency-agency seal or real-disaster imagery used.
- [ ] YouTube account access and upload explicitly approved by Jay.
- [ ] Initial visibility set only after approval.
- [ ] Captions verified after platform processing.

No upload or personal recording is authorized by this package.
